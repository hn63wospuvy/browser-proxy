Browser Proxy

Type any URL above and browse it through this server.

Profile: A saved set of settings: Search, DNS, Route and the header overrides. Switching profiles changes all four at once — handy when you have several browsing "styles".
Headers: HTTP headers overridden on every request through the proxy — e.g. User-Agent, Referer or Cookie. A matching name replaces the page's original header; a row with an empty name is skipped.

Applied to every request through the proxy. Up to 100 headers, each value ≤ 10240 bytes.
